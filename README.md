# 马尔谷福音 · 마르코 복음 중국어·영어 성경공부

마르코 복음 1–16장(100개 단락, 678절)을 **중국어 · 영어 · 한국어**로 나란히 읽으며 공부할 수 있도록 정리한 천주교 성경공부 자료입니다.

📖 **바로 보기:** https://aloha-sunhee.github.io/mark-bible-study/

## 구성

각 절은 다음 순서로 되어 있습니다.

1. **중국어 본문**: 글자마다 병음을 달았습니다.
2. **영어 본문(NAB)**: 어려운 단어에 번호를 붙여 각주로 풀이했습니다.
3. **한국어 본문**
4. **生词(단어)**: 중국어 단어, 병음, 뜻
5. **English Words**: 영어 단어, 발음기호, 뜻
6. **语法(어법)**: 필요한 곳에 예문과 함께 넣었습니다.

## 사용법

- 왼쪽 목차에서 단락을 고릅니다. 휴대폰에서는 왼쪽 위 **目录 · 목차** 단추를 누릅니다.
- 위쪽 단추로 **병음 · English · 한국어 · 단어 · 어법 · 🔊 듣기**를 각각 켜고 끌 수 있습니다. 병음을 가리고 읽기 연습을 할 때 쓰세요.
- 🔊 단추를 누르면 절 전체나 단어를 중국어·영어로 읽어 줍니다. 기기에 들어 있는 음성을 쓰므로 기기마다 목소리가 다를 수 있습니다.
- 인쇄하면 단락마다 새 페이지에서 시작합니다.

## 성경 본문 출처

| 언어 | 번역본 | 출처 |
|---|---|---|
| 중국어 | **思高汉译圣经** (思高圣经学会 Studium Biblicum O.F.M. 译, 简体) | 대만 프란치스코회가 제공하는 中英对照圣经 (https://www.ccreadbible.org/chinesebible/nab_nabhtm) |
| 영어 | **New American Bible (NAB)**: 바티칸 누리집에 실린 영어 성경 | 같은 곳 (ccreadbible.org 思高·NAB 中英对照) |
| 한국어 | **『성경』**: 한국천주교중앙협의회 번역 | 굿뉴스 성경 (https://maria.catholic.or.kr/bible/) |

- 중국어 본문은 번체로 된 원문을 간체로 바꾸었고, 명백한 오타 몇 곳(예: 遂出→逐出, 仍下→扔下, 詑异→诧异)만 바로잡았습니다.
- 절 번호는 NAB를 기준으로 맞추었습니다.
  - NAB와 한국어 『성경』에 없는 절(7,16 · 9,44 · 9,46 · 11,26 · 15,28)은 "이 절은 없습니다"로 표시했습니다.
  - 思高本에 없는 절은 "（思高本无此节）"로 표시했습니다.
- 한국어 본문에서는 전례 낭독용 문구("그때에…")와 수난 복음 배역 표시(●, ○, + 등)를 빼고 성경 본문만 실었습니다.

## 학습 자료

生词 뜻풀이, 어법 설명과 예문, 영어 단어 각주와 발음기호는 이 공부를 위해 새로 작성했습니다. 병음은 프로그램으로 만든 뒤 여러 음으로 읽히는 글자를 손으로 고쳤습니다. 틀린 곳을 발견하시면 알려 주세요.

## 파일 구조

```
index.html          완성된 공부 책 (브라우저로 바로 열 수 있음)
data/mk01a.json …   단락 제목, 生词, 어법 (장별)
data/texts.json     중국어·NAB·한국어 본문
data/notes.txt      영어 단어 각주와 발음기호
data/pinyin_fix.json  병음 교정표
tools/gen.py        index.html 생성 스크립트
tools/template.html 페이지 틀
```

내용을 고친 뒤 `index.html`을 다시 만들려면:

```bash
pip install pypinyin
python3 tools/gen.py index.html
```
