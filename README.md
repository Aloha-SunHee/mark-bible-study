# 马尔谷福音 · 마르코 복음 중국어·영어 성경공부 (현재 1–8장)

- `index.html` — 완성된 공부 책 (브라우저로 바로 열기)
- `data/mk*.json` — 단락 제목, 生词, 어법
- `data/texts.json` — 중국어(思高本 간체)·NAB·한국어 본문
- `data/notes.txt` — 영어 단어 각주와 발음기호
- `tools/gen.py` — `pip install pypinyin` 후 저장소 맨 위 폴더에서 `python3 tools/gen.py` 를 실행하면 index.html을 다시 만듭니다.
